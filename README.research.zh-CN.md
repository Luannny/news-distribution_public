# 下午科研精读邮件

新增独立的 **Research Digest** 工作流，每天北京时间 **13:00** 启动，生成后发到原来的收件邮箱。GitHub 启动及邮件送达可能延迟。原来的早上08:00综合新闻任务、筛选规则、VIX与邮箱配置均保持原样。

## 挑什么论文

- 核心：超快科学、超快电子显微/UEM、超快电子衍射/UED、飞秒/阿秒谱学、物理化学、蛋白折叠与构象动力学、生物化学。
- 质量与相关性优先，不要求当天发表。检索最近30天的论文，目标每天3–6篇；少于3篇也正常，不用无关或重复内容凑数。
- 期刊论文优先。参考 Nature、Science、Cell 及相关子刊，PRL/PRX、JACS、Angewandte、PNAS、JPCL、JCP、Chemical Science、Faraday Discussions、Biophysical Journal 等领域期刊。期刊名必须来自数据库原始元数据，不由AI编造。
- 具体还要看研究问题、方法、证据和与你研究方向的相关性。期刊名单或AI评分都不能保证论文结论正确。
- 允许预印本作为补充，明确标注“尚未同行评审”；一封最多1篇，且至少已有2篇合适期刊论文才加入。
- 排除更正、撤稿、社论、没有足够摘要的记录，以及只借用“ultrafast”等词的无关内容。

## 每篇包括什么

中文标题、英文原题、期刊与发表日期、作者、DOI、研究方法、作者报告的主要发现、为什么值得读、局限与精读核查点、免费摘要及可确认的开放全文链接。

导读基于正式元数据与作者摘要，不声称阅读全文或完成独立复现。摘要未说明的局限会标为精读时需核查的问题。预印本、模拟、实验和综述应区别对待。

Europe PMC、Crossref、arXiv 提供论文记录。数据库索引可能延迟；部分日期原始数据仅精确到月份，将明确标注。优先提供开放全文，没有可确认开放链接时只提供免费摘要记录，并说明全文可能需要机构权限，不绕过付费墙。

## 配置与使用

直接复用现有的 `GEMINI_API_KEY`、`EMAIL_USER`、`EMAIL_PASSWORD`、`EMAIL_TO`。不需要重新填写或向聊天提供密钥。模型沿用现有 Gemini 配置，增加一封邮件会增加模型调用量，仍受自己的免费额度或已开通结算条件限制；不自动切换到其他付费服务。

1. 仓库 → Actions → **Research Digest** → Run workflow。
2. 不勾选“发送科研邮件”只生成预览，不发送，也不把论文标记为已推送。
3. 成功后在 Summary 直接阅读中文预览，或下载 `research-preview` 中的 HTML。
4. 定时运行自动发送。发送成功后将论文标识写入独立的 Actions 缓存，减少日后重复；缓存丢失时可能重复。
5. 暂停这封邮件：在 Research Digest 页面右上角菜单选择 Disable workflow，不影响 Daily News Brief。

全部来源故障、期刊采集异常而只有预印本可用、AI格式检查失败时停止发送。若只是没有合适且未推送的论文，会发送诚实的“今日暂无合适论文”说明。

## 本地检查

`python -m unittest discover -s tests -p test_research.py`

`python -m src.research --collect-only` 只采集公开元数据，不调用AI、不发邮件。

`python -m src.research --dry-run` 使用环境中的现有 Gemini 密钥生成预览；不读取本地 `.env`，也不发送。
